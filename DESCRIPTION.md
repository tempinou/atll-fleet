Fleetbase est une plateforme logistique open source (édition Community, licence AGPL-3.0) : gestion de flotte et de chauffeurs, ordres de transport et de livraison, suivi en temps réel, portail client, boutique en ligne (Storefront), API publique pour vos intégrations.

Ce paquet communautaire assemble dans un seul conteneur l'API Laravel (Octane/FrankenPHP), la console web, le worker de file d'attente et le serveur temps réel SocketCluster, en s'appuyant sur les addons Cloudron pour MySQL, Redis, l'envoi de courriels et les tâches planifiées.

Connexion possible avec les comptes Cloudron (OpenID Connect) en plus des comptes Fleetbase.

Les extensions serveur livrées avec la release (Fleet-Ops, Storefront, Pallet, Ledger, IAM, Developers, Customer Portal, AI, Valhalla, Vroom) sont préinstallées. L'installation d'extensions supplémentaires depuis le registre Fleetbase n'est pas possible (système de fichiers en lecture seule).
